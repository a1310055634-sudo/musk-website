## 本轮要解决的问题

深读五篇与长卷页是全站最长的内容，但此前是「页内样式 + 14.5px 小字 + h1→h3 跳级 +
无页头大图 + 无目录 + 无阅读时长」的旧长文形态，与 V7「深色纪实封面 + 浅色长文阅读」
的定位脱节；R5 计划要求建立可复用的长文阅读模板并迁移代表性长文。

## 实际完成的改动

- style.css 新增共享 `.lr-*` 长文组件层：`.lr-hero` 深色纪实页头（近黑底/大标题/斜体
  导语/元信息行/通栏大图带署名）、`.lr-layout`（正文列 720px + 右侧目录栏）、`.lr-toc`
  （桌面 sticky / ≤960px 盒装）、引语 `.lr-quote`、数据框 `.lr-data`/`.lr-data-box`、
  编者注 `.lr-note`、来源脚注 `.lr-foot`；正文升 16.5px·行高 1.92。
- 新建 tools/build-longread.py 生成器（幂等）：五篇深读全部迁移到模板——删页内旧样式、
  h3→h2 并建 `{stem}-s{n}` 锚点、类名 dd-*→lr-* 映射、内容段落逐字保留（diff 复核）；
  每篇配已溯源纪实大图（资→弗里蒙特产线/用人→肖像/失败→星舰塔捕/监管→猎鹰重型/
  AI→Twitter 总部）+ 作者·许可署名；og:image 指向本篇大图。
- 阅读时长按实际内容计算（中文 300 字/分 + 英文 200 词/分）静态写入，无 JS 依赖；

  十章目录与既有锚点（含 controversy.html → #ch5 外链）原样保留。
- app.js 新增长文目录滚动定位（链接↔章节配对 + 高亮带相交高度取最大 + 8px 擦边门槛）；
  深读页补挂阅读进度条。

## 本轮实测发现并修复的缺陷

1. **生成器切掉 `<script src="app.js">` 开标签**：切分正则止于开标签之后，五页 app.js
   全部失载（EN/进度条/滚动定位全死）→ 修正则把开标签计入 tail，重生成。
2. **滚动定位高亮错节（两段式根因）**：① 观察对象取了无 id 的节而匹配用 en.target.id →
   改为链接↔章节配对表；② IO 把相邻节的擦边相交（0.75px）拆成单独回调批，批内取最大
   仍会让擦边节覆盖真胜者 → 相交高度加 8px 参选门槛。
3. **锚点落点钻进 sticky 报头底下**：报头实为 sticky 121px（此前 grep 截断误判非
   sticky），h2 scroll-margin 20px 不够 → 实测报头高度后统一改 132px（.lr-sec/.lr-sec h2/
   reading 的 .rd-ch 同步）。
4. 探针自身两处断言 bug（EN 图注截断 30 字符致匹配失败；手机截图在页面循环外拍摄致
   两张均落到 reading）——修正并补拍正确的 dd01 真 390 证据。
